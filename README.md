# RK Everyday Apps

A responsive, static landing page for a collection of thoughtful everyday apps.

## Publish with GitHub Pages

Push this folder to a GitHub repository, then open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select your default branch and the `/ (root)` folder, then save.

The site has no build step or external dependencies. Open `index.html` locally to preview it.
